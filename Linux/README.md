特点：多用户，多任务，多线程和多CPU的操作系统

## 1.Linux和Windows区别

| 比较       | Linux                               | Windows                   |
| ---------- | ----------------------------------- | ------------------------- |
| 费用       | 绝大多数免费                        | 收费                      |
| 软件与支持 | 开源自由软件                        | 数量和质量的优势          |
| 安全性     | 更加稳定安全                        | 更新频繁，会中病毒木马    |
| 使用习惯   | 新手入门困难                        | 入门简单                  |
| 可制定性   | 开源，可制定性非常强                | 图封闭的，系统可制定性差  |
| 应用场景   | 大部分软件和服务都是运行在Linux上的 | 桌面操作系统主要是Windows |

**VMware中三种网络模式**：

1.桥接模式：宿主机和Linux网段一样  

​	可能问题：IP冲突，不安全

2.NAT网络地址转换：宿主机和Linux网段不一样，Linux和VMnet8的网段一样 。数据发送给 VMnet8 在发送给 宿主机或者Linux。避免了IP冲突和不安全问题。

3.仅主机模式：宿主机和Linux网段不一样，Linux和VMnet8的网段一样 。数据发送给 VMnet1 在发送给 宿主机或者Linux。避免了IP冲突和不安全问题。【和NAT网络地址转换模式区别，不支持外网】

## 2.Linux文件与目录结构

### 目录结构【**Linux系统一切皆文件**】

| 目录      | 用途                                    | 说明                                         |
| --------- | --------------------------------------- | -------------------------------------------- |
| `/`       | 根目录                                  | 所有目录的起点，一切从这开始                 |
| ⭐`/bin`   | 基础命令的可执行文件【usr/bin的软连接】 | `ls`、`cp`、`mv`、`cat` 等所有用户可用       |
| `/sbin`   | 管理员命令【usr/sbin的软连接】          | `reboot`、`fdisk`、`iptables`，需 sudo       |
| ⭐`/home`  | 用户目录                                | `/home/用户名/`，你的代码放这里              |
| `/root`   | 系统管理员，root 用户家目录             | root 用户专用，不在 `/home/` 里              |
| `/lib`    | 动态连接共享库                          | 类似 Windows 的 DLL，被 `/bin`、`/sbin` 依赖 |
| ⭐`/etc`   | 系统管理的环境配置文件和子目录          | **系统和服务配置的核心，重点！**             |
| ⭐`/usr`   | 用户的应用程序和文件                    | **软件安装主目录，重点！**                   |
| `/boot`   | 启动文件                                | 内核（vmlinuz）、引导程序（grub）            |
| ⭐`reboot` | **重启（命令）**                        | ⭐                                            |
| `/run`    | 运行时数据                              | 进程 PID、锁文件，重启清空                   |
| ⭐`/proc`  | 进程的虚拟镜像的目录，进程信息          | **虚拟文件系统**，内核动态生成               |
| `/srv`    | 服务数据                                | Web、FTP 服务的数据目录                      |
| `/sys`    | 系统硬件信息                            | **虚拟文件系统**，内核动态生成               |
| `/tmp`    | 临时文件                                | 所有用户可读写，**重启清空**                 |
| ⭐`/dev`   | 设备文件                                | 硬盘 `sda`、终端 `tty`、黑洞 `null`          |
| `/media`  | 自动挂载设备                            | U 盘、光盘插入后自动挂载到这                 |
| `/mnt`    | 手动挂载点                              | 手动挂载硬盘、网络存储                       |
| ⭐`/opt`   | 第三方软件                              | 大型第三方软件（如 Chrome、Docker）          |
| ⭐`/var`   | 可变数据                                | **日志、缓存、数据库，重点！**               |
| `/lib64`  | 64 位共享库                             | 64 位系统的共享库                            |

【**挂载：让硬件设备和系统目录之间建立自动连接**】

| `apt list --upgradable`         | 列出可升级的包                 | 查看待升级               |
| `sudo apt --fix-broken install` | 修复依赖损坏                   | 安装失败时用             |
| `sudo dpkg -i xxx.deb`          | 安装本地 deb 包                | 手动下载的包             |

| 其他人 | `o` (other) | 既不是所有者也不在所属组中的用户 |
| 所有人 | `a` (all)   | `u+g+o` 的简写                   |

#### 2. 三种权限

| 权限 | 符号 | 数字 | 对文件的意义          | 对目录的意义                 |
| ---- | ---- | ---- | --------------------- | ---------------------------- |
| 读   | `r`  | 4    | 查看文件内容          | 列出目录内容（`ls`）         |
| 写   | `w`  | 2    | 修改文件内容          | 在目录中创建/删除/重命名文件 |
| 执行 | `x`  | 1    | 执行文件（脚本/程序） | 进入目录（`cd`）             |

#### 3. `ls -l` 输出解读【文件属性】

```

```

| 部分          | 含义                                                         |
| ------------- | ------------------------------------------------------------ |
| `-`           | 文件类型：`-` 普通文件，`d` 目录，`l` 链接，`b` 块设备，`c` 字符设备，`s` 套接字，`p` 管道 |
| `rwx`         | 所有者权限：读、写、执行                                     |
| `r-x`         | 所属组权限：读、执行                                         |
| `r--`         | 其他人权限：只读                                             |
| `1`           | 硬链接数                                                     |
| `alice`       | 所有者                                                       |
| `developers`  | 所属组                                                       |
| `1024`        | 文件大小（字节）                                             |
| `Oct 8 10:00` | 最后修改时间                                                 |
| `script.sh`   | 文件名                                                       |

#### 4.权限修改⭐

##### 1. 符号模式

chmod \[ugoa]\[+-=]\[rwx] 文件

u：所有者  g：所有组  o：其他人  a：所有人（u，g，o总和）

+ +添加权限，- 移除权限，= 设置精确权限。

- 可同时操作多类：u+rwx，g+rx，o-rwx。


##### 2. 数字模式

- 每位数字 = `r(4) + w(2) + x(1)` 的和。
- 顺序：所有者、所属组、其他人。

| 数字 | 权限 | 含义       |

| 6    | rw-  | 读+写      |
| 5    | r-x  | 读+执行    |
| 4    | r--  | 只读       |
| 3    | -wx  | 写+执行    |
| 2    | -w-  | 只写       |
| 1    | --x  | 只执行     |
| 0    | ---  | 无权限     |

### 11.进程线程类

#### 1.ps 查看当前系统进程状态

##### 	1.语法：	

​		ps -aux  （功能描述：查看系统中所有进程）

​		ps -ef  （功能描述：可以查看子父进程之间的关系）

| **选项** | **功能**               |
| -------- | ---------------------- |
| **-a**   | 选择所有进程           |

| **-x**   | 显示没有终端的进程     |

##### 	2.功能说明

###### 		1.ps -aux显示信息说明

**USER：该进程是由哪个用户产生的**

 **PID：进程的ID号**

 **%CPU：该进程占用CPU资源的百分比，占用越高，进程越耗费资源；**

 %MEM：该进程占用物理内存的百分比，占用越高，进程越耗费资源；

 **VSZ：该进程占用虚拟内存的大小，单位KB；**

 RSS：该进程占用实际物理内存的大小，单位KB；

 TTY：该进程是在哪个终端中运行的。其中tty1-tty6代表系统的虚拟控制台。pts/0-255代表伪终端,通常用于 SSH 会话、telnet 会话以及其他远程登录会话。

 STAT：进程状态。常见的状态有：R：运行、S：睡眠、T：停止状态、s：包含子进程、+：位于后台、I<：几乎没有使用CPU时间

 START：该进程的启动时间

 TIME：该进程占用CPU的运算时间，注意不是系统时间

 **COMMAND：产生此进程的命令名**

###### 		2.ps -ef显示信息说明

 UID：用户名

  **PID：进程ID** 

 **PPID：父进程ID** 

 C：CPU用于计算执行优先级的因子。数值越大，表明进程是CPU密集型运算，执行优先级会降低；数值越小，表明进程是I/O密集型运算，执行优先级会提高 

 STIME：进程启动的时间 

 TTY：该进程是在哪个终端中运行的。 

 TIME：CPU时间 

 CMD：启动进程所用的命令和参数

###### （1）* * * * * 执行的任务，*的含义

###### （2）特殊符号

| **特殊符号** | **含义**                                                     |

| **-**        | 代表连续的时间范围。比如“0 5  *  *  1-6命令”，代表在周一到周六的凌晨5点0分执行命令 |
| ***/n**      | 代表每隔多久执行一次。比如“*/10  *  *  *  *  命令”，代表每隔10分钟就执行一遍命令 |
