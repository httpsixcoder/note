## 1.Linux和Windows区别

| 比较       | Linux                               | Windows                   |

## 2.Linux文件与目录结构

### 目录结构【**Linux系统一切皆文件**】

| 目录     | 用途                                    | 说明                                         |
| -------- | --------------------------------------- | -------------------------------------------- |
| `/`      | 根目录                                  | 所有目录的起点，一切从这开始                 |
| ⭐`/bin`  | 基础命令的可执行文件【usr/bin的软连接】 | `ls`、`cp`、`mv`、`cat` 等所有用户可用       |
| `/sbin`  | 管理员命令【usr/sbin的软连接】          | `reboot`、`fdisk`、`iptables`，需 sudo       |
| ⭐`/home` | 用户目录                                | `/home/用户名/`，你的代码放这里              |
| `/root`  | 系统管理员，root 用户家目录             | root 用户专用，不在 `/home/` 里              |
| `/lib`   | 动态连接共享库                          | 类似 Windows 的 DLL，被 `/bin`、`/sbin` 依赖 |
| ⭐`/etc`  | 系统管理的环境配置文件和子目录          | **系统和服务配置的核心，重点！**             |
| ⭐`/usr`  | 用户的应用程序和文件                    | **软件安装主目录，重点！**                   |
| `/boot`  | 启动文件                                | 内核（vmlinuz）、引导程序（grub）            |
| `/run`   | 运行时数据                              | 进程 PID、锁文件，重启清空                   |
| ⭐`/proc` | 进程的虚拟镜像的目录，进程信息          | **虚拟文件系统**，内核动态生成               |
| `/srv`   | 服务数据                                | Web、FTP 服务的数据目录                      |
| `/sys`   | 系统硬件信息                            | **虚拟文件系统**，内核动态生成               |
| `/tmp`   | 临时文件                                | 所有用户可读写，**重启清空**                 |
| `/dev`   | 设备文件                                | 硬盘 `sda`、终端 `tty`、黑洞 `null`          |
| `/media` | 自动挂载设备                            | U 盘、光盘插入后自动挂载到这                 |
| `/mnt`   | 手动挂载点                              | 手动挂载硬盘、网络存储                       |
| ⭐`/opt`  | 第三方软件                              | 大型第三方软件（如 Chrome、Docker）          |
| ⭐`/var`  | 可变数据                                | **日志、缓存、数据库，重点！**               |
| `/lib64` | 64 位共享库                             | 64 位系统的共享库                            |

## 3.APT软件包管理器

### 常用命令

| 命令                            | 作用                           | 示例                     |
| ------------------------------- | ------------------------------ | ------------------------ |
| `apt list --installed`          | 列出已安装的包                 | 查看已装软件             |
| ⭐`apt search 关键字`            | 搜索软件包                     | `apt search python3`     |
| ⭐`sudo apt install 包名`        | 安装软件包                     | `sudo apt install nginx` |
| `sudo apt reinstall 包名`       | 重新安装软件包                 |                          |
| ⭐`sudo apt remove 包名`         | 卸载软件包（保留配置）         | `sudo apt remove nginx`  |
| `sudo apt autoremove`           | 自动清理不再需要的依赖         | 清理旧内核               |
| ⭐`sudo apt update`              | 更新软件源索引（不升级软件）   | 装软件前先执行           |
| `sudo apt upgrade`              | 升级已安装的软件包（不删包）   | 定期升级                 |
| `sudo apt full-upgrade`         | 升级并处理依赖变化（可能删包） | 大版本升级               |
| `sudo apt edit-sources`         | 编辑软件源                     | 换国内源                 |
| `sudo apt purge 包名`           | 彻底卸载（连配置一起删）       | `sudo apt purge nginx`   |
| `sudo apt autoclean`            | 清理过期的包缓存               | 释放磁盘                 |
| `sudo apt clean`                | 清理所有包缓存                 | 释放磁盘                 |
| `apt show 包名`                 | 查看包详细信息                 | `apt show nginx`         |
| `apt list --upgradable`         | 列出可升级的包                 | 查看待升级               |
| `sudo apt --fix-broken install` | 修复依赖损坏                   | 安装失败时用             |
| `sudo dpkg -i xxx.deb`          | 安装本地 deb 包                | 手动下载的包             |

注意：当修改删除时候权限不足，需要在前面加上 sudo【以管理员权限来操作】

#### 1. 三类用户

#### 2. 三种权限

| 权限 | 符号 | 数字 | 对文件的意义          | 对目录的意义                 |
| ---- | ---- | ---- | --------------------- | ---------------------------- |
| 读   | `r`  | 4    | 查看文件内容          | 列出目录内容（`ls`）         |
| 写   | `w`  | 2    | 修改文件内容          | 在目录中创建/删除/重命名文件 |
| 执行 | `x`  | 1    | 执行文件（脚本/程序） | 进入目录（`cd`）             |

#### 3. `ls -l` 输出解读【文件属性】

```
-rwxr-xr-- 1 alice developers 1024 Oct 8 10:00 script.sh
```

| 部分          | 含义                                                         |
| ------------- | ------------------------------------------------------------ |
| `-`           | 文件类型：`-` 普通文件，`d` 目录，`l` 链接，`b` 块设备，`c` 字符设备，`s` 套接字，`p` 管道 |
| `rwx`         | 所有者权限：读、写、执行                                     |
| `r-x`         | 所属组权限：读、执行                                         |
| `r--`         | 其他人权限：只读                                             |
| `1`           | 硬链接数                                                     |
| `alice`       | 所有者                                                       |
| `developers`  | 所属组                                                       |
| `1024`        | 文件大小（字节）                                             |
| `Oct 8 10:00` | 最后修改时间                                                 |
| `script.sh`   | 文件名                                                       |

#### 4.权限修改

##### 1. 符号模式

chmod \[ugoa]\[+-=]\[rwx] 文件

u：所有者  g：所有组  o：其他人  a：所有人（u，g，o总和）

+ +添加权限，- 移除权限，= 设置精确权限。

- 可同时操作多类：u+rwx，g+rx，o-rwx。


##### 2. 数字模式

chmod 755 文件

- 每位数字 = `r(4) + w(2) + x(1)` 的和。
- 顺序：所有者、所属组、其他人。

| 数字 | 权限 | 含义       |
| ---- | ---- | ---------- |
| 7    | rwx  | 读+写+执行 |
| 6    | rw-  | 读+写      |
| 5    | r-x  | 读+执行    |
| 4    | r--  | 只读       |
| 3    | -wx  | 写+执行    |
| 2    | -w-  | 只写       |
| 1    | --x  | 只执行     |
| 0    | ---  | 无权限     |

#### 5.修改所有者/所属组

##### 1. `chown` 修改所有者和组

```
chown [选项] 用户[:组] 文件
```

| 选项                   | 说明                     |
| ---------------------- | ------------------------ |
| `-R`                   | 递归                     |
| `--reference=参考文件` | 使用参考文件的属主和属组 |

##### 2. `chgrp` 修改所属组

```
chgrp [选项] 组 文件
```
