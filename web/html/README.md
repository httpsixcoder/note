# HTML基础学习笔记（仅HTML+HTML5）

## 1 Web基础与技术体系（客户端、服务器、三层技术划分）

### 1.1 客户端（浏览器）

**作用**

1. 接收用户输入的数据
2. 向服务端发送HTTP请求
3. 接收服务器返回的数据，渲染展示页面

**常见客户端**：PC网页浏览器、移动端H5网页。

### 1.2 服务器

> 服务器分为硬件和软件两层概念

- **硬件**：高性能计算机，负载更高，专门用于网络服务。

- 软件

    ：安装在硬件机器上的服务程序。

    - 应用服务器：Uvicorn(FastAPI)、Tomcat
    - 数据库服务器：MySQL
    - 缓存服务器：Redis

**服务器作用**

1. 接收客户端发来的请求
2. 处理业务逻辑，给客户端返回响应结果
3. 持久化保存业务数据

**服务器操作系统**

1. **Linux**：线上生产环境主流，开源、稳定、性能强。
2. Unix：商用，与硬件绑定。
3. Windows Server：线上很少使用。

### 1.3 三层技术体系划分

1. **客户端技术（浏览器端运行）**

- HTML：搭建网页结构、骨架
- CSS：页面美化
- JavaScript：实现页面交互效果

1. **服务端技术（服务器运行）** Python：FastAPI、Uvicorn；Java：Tomcat、Servlet。

    > 后端开发就是编写运行在服务器上的业务应用程序。

2. **持久层技术** MySQL数据库、数据库连接池；负责数据存储、读写。

> 请求响应完整流程：浏览器发起请求 → 网络传输到服务器 → 后端程序执行业务 → 返回HTML/JSON数据 → 浏览器解析渲染页面。

## 2 HTML基础

### 2.1 HTML与HTML5介绍

**HTML**：超文本标记语言

- **超文本**：不只是普通文本，可以嵌入图片、音频、视频、超链接。
- **标记语言**：全部由标签构成，**不是编程语言，没有循环、判断逻辑**。

**HTML5** HTML第5个版本，替代旧版HTML4，重点面向移动端。

- 特性：一份网页，PC、手机多设备自适应显示。
- 主流支持浏览器：Chrome、Firefox、Safari；旧版IE兼容性差。

### 2.2 标签分类

1. **双标签（闭合标签）**

```
<开始标签>标签内容/子标签</结束标签>
```

> 开始标签和结束标签中间叫**标签体**，可以放文本，也可以嵌套其他子标签。

1. **单标签（自闭合标签）**

```
<br />
<img />
<hr />
```

### 2.3 标签属性

写在**开始标签**内部，格式：`属性名="属性值"`，建议使用双引号包裹属性值。

```
<标签名 属性1="值1" 属性2="值2"></标签名>
```

### 2.4 HTML5标准网页骨架

```
<!DOCTYPE html>
<!-- 文档声明，必须写在第一行，告诉浏览器这是HTML5文档 -->
<html lang="zh‑CN">
<!-- lang 设置网页语言，zh‑CN中文，en英文 -->
<head>
    <!-- head：网页元信息，内容不会直接显示在页面上 -->
    <meta charset="UTF‑8">
    <!-- charset 设置字符编码，UTF‑8防止中文乱码 -->
    <title>网页标题</title>
    <!-- title：浏览器标签栏显示的标题 -->
</head>
<body>
    <!-- body：页面所有可见内容全部写在这里 -->
</body>
</html>
```

> 注释语法：`<!-- HTML注释内容 -->`，注释不会被浏览器渲染显示。

## 3 HTML常用标签

### 3.1 基础文本标签

#### 标题标签 `<h1> ~ <h6>`

一共6级标题；h1字号最大，h6字号最小。

> 规范：一个页面建议只写**一个h1**，利于搜索引擎SEO。

```
<h1>一级标题</h1>
<h2>二级标题</h2>
```

#### 水平分割线 `<hr />`

属性

- `color`：分割线颜色
- `size`：分割线粗细（像素）

```
<hr color="red" size="2" />
```

#### 换行标签 `<br />`

单纯实现文字换行，**没有行间距**。

#### 段落标签 `<p></p>`

表示文章段落；自带换行，**自带上下行间距**。

```
<p>第一段文字</p>
<p>第二段文字</p>
```

#### 文本格式化标签

| 标签      | 作用       |
| --------- | ---------- |
| `<b></b>` | 文字加粗   |
| `<u></u>` | 文字下划线 |
| `<i></i>` | 文字斜体   |

> 标签支持互相嵌套：`<b><i>加粗倾斜文字</i></b>`

#### 空格转义字符

浏览器会把多个连续空格合并为1个；需要显示多个空格使用 `&nbsp;`

```
用&nbsp;&nbsp;&nbsp;实现多个空格
```

### 3.2 图片标签 `<img />`（单标签）

```
<img src="图片路径" alt="图片加载失败提示文字" title="鼠标悬浮提示" width="200" />
```

| 属性    | 说明                                   |
| ------- | -------------------------------------- |
| `src`   | 图片路径，支持相对路径、网络绝对url    |
| `alt`   | 图片加载失败时展示的替代文字，建议必写 |
| `title` | 鼠标悬浮在图片上弹出的提示文字         |
| `width` | 图片宽度；`height`图片高度             |

> ✨最佳实践：**只设置width，不设置height，图片自动等比例缩放，避免拉伸变形**。

路径说明

- 相对路径：`./img/1.jpg` 当前目录；`../img/1.jpg` 返回上一级目录。
- 绝对路径：完整网络地址 `https://xxx/xx.jpg`。

### 3.3 超链接 `<a></a>`

用于页面跳转、跳转外部网站。

```
<a href="目标地址" target="_blank">点击跳转</a>
```

| 属性     | 取值                    | 说明                               |
| -------- | ----------------------- | ---------------------------------- |
| `href`   | 目标url或者本地html文件 | 跳转地址；`href="#"`跳转到页面顶部 |
| `target` | `_self`                 | 默认，在**当前标签页**打开页面     |
|          | `_blank`                | 在**新浏览器标签页**打开页面       |

> 小技巧：`href="javascript:void(0);"`，点击链接不跳转，用于后续绑定JS点击事件。

### 3.4 表格标签

- `<table>`：整个表格的容器
- `<tr>`：table‑row，代表表格**一行**
- `<td>`：table‑data，普通单元格
- `<th>`：table‑header，表头单元格，文字默认加粗居中

<table>常用属性

| 属性             | 说明                                         |
| ---------------- | -------------------------------------------- |
| `border`         | 边框像素宽度                                 |
| `width`          | 表格宽度，可以写像素，也可以百分比自适应窗口 |
| `cellspacing`    | 单元格之间空隙；写`0`消除单元格缝隙          |
| `cellpadding`    | 文字距离单元格边框的内边距                   |
| `align="center"` | 让整个表格在页面居中                         |

#### 单元格合并

写在`<td>`或`<th>`标签上

1. `rowspan="N"`：**跨行合并（垂直方向）**；合并完成需要删除被占用的单元格标签。
2. `colspan="N"`：**跨列合并（水平方向）**；合并完成需要删除被占用的单元格标签。

示例

```
<table border="1" cellspacing="0" width="400">
    <tr>
        <td rowspan="2">垂直合并两行</td>
        <td>A</td>
    </tr>
    <tr>
        <td>B</td>
    </tr>
    <tr>
        <td colspan="2">水平合并两列</td>
    </tr>
</table>
```

> VSCode快捷生成表格：输入 `tr*3>td*3` 按下Tab，快速生成3行3列表格。

### 3.5 div 和 span

#### div 块级元素

```
<div>内容</div>
```

1. **独占完整一行，自动换行**。
2. 主要用于页面布局。

#### span 行内元素

```
<span>内容</span>
```

1. 多个span在**同一行并排显示，不会自动换行**。
2. 用于对一小段局部文字做处理。

> 常见块级：div、h1‑h6、p；常见行内：span、b、i、u。

## 4 表单 form【重点】input、select、GET&POST

> 表单核心作用：收集用户在页面输入的数据，提交给后端服务程序。

### 4.1 form外层标签

```
<form action="/api/login" method="post">
    <!-- 所有输入控件写在form标签内部 -->
</form>
```

| 属性     | 说明                                                         |
| -------- | ------------------------------------------------------------ |
| `action` | 后端接口URL，数据提交的目标地址；`action="#"`提交到当前页面，用于本地测试 |
| `method` | 请求提交方式，取值 `get` / `post`，大小写不敏感              |

### 4.2 input输入控件

`<input />` 单标签；**type属性决定控件的类型**。

> ⚠️重要：控件想要把数据提交给后端，**必须设置name属性！没有name，该条数据不会被提交！**

1. **普通文本框 type="text"**

```
用户名：<input type="text" name="username" placeholder="请输入用户名" value="" />
```

- `name`：后端获取参数的key
- `placeholder`：灰色输入提示，**不会提交给服务器**
- `value`：真正提交给后端的数据；用户输入内容本质就是修改value。

1. **密码框 type="password"** 输入内容圆点隐藏；属性与text完全一致。

2. **单选框 type="radio"**

    > 同一组单选框，**name属性值必须完全相同，才能实现互斥单选**。

```
性别：
<input type="radio" name="gender" value="male" checked />男
<input type="radio" name="gender" value="female" />女
```

- `checked`：设置默认选中；可以简写只写`checked`。
- `value`：提交给后端的真实数值；页面显示文字写在标签外部。

1. **复选框 type="checkbox"** 多选控件，同一组复选框name保持一致。

```
爱好：
<input type="checkbox" name="hobby" value="read">阅读
<input type="checkbox" name="hobby" value="game">游戏
```

1. 文件上传 `type="file"`

     选择本地文件上传。

    > 如果表单包含文件上传：form标签必须额外增加 `enctype="multipart/form‑data"`，否则后端接收不到文件。

```
<form action="" method="post" enctype="multipart/form‑data">
    <input type="file" name="avatar" />
</form>
```

1. input按钮类型

    | type     | 作用                                   |
    | -------- | -------------------------------------- |
    | `submit` | 提交按钮，点击把整个表单数据发送给后端 |
    | `reset`  | 重置表单，恢复所有输入控件初始状态     |
    | `button` | 普通按钮，**不会提交表单，用于JS逻辑** |
    | `image`  | 图片样式的提交按钮，src指定图片地址    |

### 4.3 下拉选择框 select

```
<select name="city">
    <option value="bj">北京</option>
    <option value="sh" selected>上海</option>
    <option value="gz">广州</option>
</select>
```

- `<select>`外层，**必须写name属性**。
- `<option>`：每一个下拉选项；`value`是提交后端的数据。
- `selected`：设置该选项默认选中。
- `multiple`属性：开启多选下拉，实际开发很少使用。

### 4.4 GET 和 POST 表单提交对比（面试高频）

| 对比项   | GET                                               | POST                                           |
| -------- | ------------------------------------------------- | ---------------------------------------------- |
| 参数位置 | 拼接在浏览器地址栏URL后面，格式`?key=value&k2=v2` | 存放在**请求体request body**，地址栏看不到参数 |
| 安全性   | 参数明文可见，**禁止传递密码等敏感数据**          | 相对安全，不等于加密                           |
| 数据大小 | 浏览器URL有长度上限，适合少量简单参数             | 几乎无大小限制，支持大文本、文件上传           |
| 适用场景 | 查询、搜索业务                                    | 登录注册、表单提交、文件上传                   |

> ⚠️文件上传**只能使用POST方式提交**。

## 5 高频避坑总结

1. HTML中文乱码：`<meta charset="UTF‑8">` 必须写在head标签内。
2. form表单输入控件**缺少name属性，对应数据不会提交到后端**。
3. radio单选框：同一组单选必须name完全相同，否则无法互斥选择。
4. 文件上传表单：必须同时配置 `method="post"` 和 `enctype="multipart/form‑data"`。
5. img图片标签：建议只设置width，不写height，防止图片拉伸变形；alt属性尽量写。
6. id属性：同一个HTML页面中id值必须唯一。
7. 标签嵌套要规范，禁止交叉嵌套；标签名全部小写。
8. HTML多个连续空格会被合并；需要空格使用转义字符 `&nbsp;`。
9. `<!DOCTYPE html>` 文档声明不能省略，缺失会触发浏览器怪异模式，页面解析异常。
10. 超链接 `target="_blank"` 新窗口打开；`href="#"` 回到页面顶部。
11. 单元格合并操作完成后，**必须删除被合并占用的td标签，否则表格错乱**。
12. placeholder仅仅是输入框提示文字，不会提交给服务器；真正提交的是value。

## 6⭐Emmet 语法速查表（VSCode HTML 快捷键）

| 符号     | 作用                      |
| -------- | ------------------------- |
| `>`      | 子级（下一层标签）        |
| `+`      | 同级兄弟标签              |
| `*n`     | 重复 n 次                 |
| `$`      | 自增序号                  |
| `@n`     | 设置起始数字              |
| `@-`     | 倒序                      |
| `$$$`    | 补零                      |
| `()`     | 分组，把一组标签打包重复  |
| `[]`     | 写标签属性                |
| `{}`     | 标签内文本                |
| `loremN` | 生成 N 个单词的占位假文本 |

例子：

```html
基础序号 `$`
	缩写：`ul>li{$}*5`
	缩写：`div.class${value$}*3`
指定起始序号 `@数字`
	缩写：`ul>li{章节$@3}*4`
倒序 `@-`
	缩写：`ul>li{序号$@-}*4`
补零序号 `$$$`（三位补零）
	缩写：`div.box$$$*3`
属性 + 文本
	缩写：`a[href="./page$.html"]{页面$}*3`
分组 `()`，一组多个标签
	缩写：`(div>h3{标题$}+p{内容$})*3`
随机占位文本 lorem
	缩写：`div.card*3>h2{标题$}+p>lorem10`
```
